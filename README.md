# Breast Cancer AI

A deep learning research project exploring the classification of breast histopathology images into four categories: Normal, Benign, In Situ Carcinoma, and Invasive Carcinoma.

## Objectives

* Develop a four-class image classification model using PyTorch.
* Apply transfer learning to improve model performance.
* Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
* Develop an interactive GUI for image classification.

## Technology

* Python
* PyTorch and Torchvision
* Google Colab (GPU training)
* Scikit-learn
* Gradio (planned interface)

## Dataset

Breast histopathology images obtained from [Zenodo](https://zenodo.org/records/3632035).

The dataset is organised into four classes:

* Normal
* Benign
* In Situ Carcinoma
* Invasive Carcinoma

Dataset use and attribution will follow the applicable licence.

## Project Status

Currently in development. Model training, evaluation, and GUI implementation are planned.

## Disclaimer

This project is for educational and research purposes only. It is not a clinically validated diagnostic tool and must not be used to make medical decisions.
